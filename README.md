# Form Validation 📝

### Smart and User-Friendly Registration Form

Form Validation is a simple registration form that allows users to enter their personal information with input validation.

### ✨ Features
- Username input
- Email address validation
- Password input
- Confirm password field
- User-friendly registration form
- Persian interface

### 🛠️ Technologies
- HTML5
- CSS3
- JavaScript
